# Ricochet
This is Ricochet, a Breakout-style game with a retro aesthetic and modern influences. It has been coded with HTML and you can use A/D or the left/right arrow keys to move the paddle, and the spacebar or cursor (at the beginning of the game) for launching the ball from the paddle. You have three lives, and get five points per block hit. Blocks with a white line at the bottom must be hit twice to fully break. You can export or import your game.
